Banca Digital
Sistema de banca digital desarrollado como proyecto académico de Ingeniería de Software.

Demo en línea
Frontend desplegado en Render
https://bancadigital-frontend.onrender.com

Tecnologías utilizadas
- Java y Spring Boot
- Angular
- PostgreSQL y Supabase
- JDBC y patrones de diseño: Singleton, DAO y Factory
Funcionalidades
- Inicio de sesión por roles.
- Gestión de usuarios y parámetros.
- Módulos de acuerdo con el rol del usuario.
